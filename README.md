# MOVINCAM.ART

Photography and Videography Website
with Custom Quotation Generator.

## Files

- index.html
- style.css
- app.js

## Features

1. Professional photography website.
2. Wedding and event services.
3. Custom quotation builder.
4. Editable individual service prices.
5. Custom quantities.
6. Add and remove services.
7. Discount calculator.
8. GST/tax calculator.
9. Advance payment calculator.
10. PDF quotation generator.
11. Save and reopen quotations.
12. Export and import saved quotations.

## Setup

1. Download the source ZIP.
2. Extract all files.
3. Upload all files to GitHub.
4. Open Settings.
5. Open Pages.
6. Select main branch.
7. Select root folder.
8. Save.

## Business Configuration

Open app.js.

Update:

STUDIO.phone
STUDIO.email
STUDIO.city

Change standard prices inside PRICE_LIST.

## Important

Each quotation has its own price copies.
Changing a client quotation will not change
the standard price list.

Saved quotations are stored in the browser.
Export JSON backups regularly.
